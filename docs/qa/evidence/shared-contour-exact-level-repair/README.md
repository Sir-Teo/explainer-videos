# Shared exact-level contour repair

The old shared `contour_segments` accepted only strict sign-product crossings, omitting vertices/edges exactly on the requested level. On f(x,y)=x, xs=ys=[-1,0,1], level 0 it emitted no segments. The repaired helper retains the vertical contour and closes verified interior gaps in Part 4 Quadratic's completed valley grid.

The patch changes only `explainer/ai/viz.py`'s contour function, its new private interpolation helper and an explicit math import. Exact source-text comparison proves every other region unchanged; normalized AST comparison binds the implementation to reviewed candidate 2736d100. No SVD scene/package/pilot pins, numerical producer, cache metadata, captions, levels or dependencies were modified by this repair.

The contract preserves no-contour output for entirely flat-at-level grids. Plateau zero edges are emitted only beside a non-flat cell; domain-only flat borders are suppressed. Whole zero edges are unique and split at transverse branch junctions; isolated point solutions and flat-region interiors are omitted by the segment API. Integer axes convert to float64 before subtraction and must be exactly binary64-representable; intermediate geometry retains ordinary float64 rounding. Nonzero four-crossing saddles intentionally retain legacy perimeter-order pairing, without introducing an asymptotic decider.
