The concrete correction concerns GaLore. The published paper reports its completed large run on 64 A100 GPUs and separately establishes a memory footprint compatible with 24 GB under the stated small-batch, 8-bit and per-layer-update conditions. The original scene incorrectly described a completed one-card run. After reporting this to the parent, one history caption, one English narration expression and its matching Chinese entry were corrected to memory feasibility. All three bookmarks, numerical data, algorithm and explicit animation timings are unchanged. Existing narration tests passed ten cases; actual bilingual Manim text geometry passed. The exact edit, source freeze, caption handoff and checks are included.
