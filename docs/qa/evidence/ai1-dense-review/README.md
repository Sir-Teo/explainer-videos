# Part 1 dense review evidence

The Markdown reports provide readable coverage, findings and limits. Large companion JSON ledgers are stored
as deterministic gzip files to keep the source review manageable. `ledger-manifest.json` records their original
and compressed hashes and sizes. Decompression reproduces the exact original review bytes.

For example: `gzip -dc ai1-hook-complete-motion-review.json.gz | python -m json.tool`.

Every selected time retains its explicit direct-view or exact-PNG inheritance proof. These records distinguish
selected-content review from all decoded frames, continuous perceptual viewing and audio listening. References
to `/workspace/runtime/` or `renders/qa/` describe the cloud evidence paths captured during this run.
