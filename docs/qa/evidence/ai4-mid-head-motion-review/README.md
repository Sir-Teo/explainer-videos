# Part 4 chapters 6–10: original bilingual motion review

All ten original silent preview movies were algorithmically decoded. Every bounded-gap selection was covered by an actually viewed exact RGB-pixel representative: all 374 chronological contact-sheet pages and 47 native follow-ups were inspected. Each source frame, selected time, PNG SHA, exact pixel hash, representative/page mapping and page SHA is retained in the compressed ledgers. Contact-sheet tiles are 640 pixels wide, scaled from 854×480 native previews; critical text/math/transition cases were re-opened at native size.

Modes and Library had no concrete motion defect. Backprop, Train and Floats each showed copied previous equations crossing their still-visible originals during later derivation reveals. These are actual motion-only findings, with native evidence retained here. The local scenes were repaired using the existing ladder `transform=False` option, preserving settled geometry, numeric inputs, narration, bookmarks and run times. The shared helper is unchanged. This directory preserves the original review, including its confirmed defects; it is not approval of those old transitions. Fresh focused regression evidence is packaged separately in sibling Backprop/Train/Floats reveal-repair directories as those reviews complete.

`coverage.json` separates whole-file algorithmic decoding, selected positions, actually viewed unique representatives and exact-pixel duplicate coverage. It preserves each raw runtime status/warning. Source snapshots (including tool and translation table) are content-addressed and compressed; input hashes and small raw numerical inputs are retained without invoking producers. Raw records and audits preserve broad fingerprints, conservative warnings, every motion selection and unextracted interval. Direct scene-source scope must be distinguished from later unrelated whole-part source changes.

Coverage uses the frozen `qa_motion.py`, RGB transition analysis, a 0.5-second dense setting and no more than one second between selected frames. All selected positions were reviewed through unique representatives; this is not a claim that every encoded frame was perceptually watched. Continuous playback, narrated audio/listening/synchronization, production-resolution motion, and unselected frame intervals remain unverified. Full frozen movies, all selected PNGs and all viewed sheets remain in the cloud runtime paths named in the ledgers, not duplicated into Git.
